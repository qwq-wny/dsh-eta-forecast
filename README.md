# dsh-eta-forecast

给 DeepSeek Harness 的 Web / 桌面界面加一个「**这一轮大概几点做完**」的小挂件。

它不是按字数、按步数拍脑袋外推的。真正被当成进度分母的是 **todo 清单**——
模型被要求「开工前先列清单、做完就勾」；步数只用来估「一条 todo 平均要几步」，
是节奏修正项，不是进度本身。

## 它显示什么

| 位置 | 内容 |
| --- | --- |
| 大字 | 预计完成时刻（本地时钟，如 `14:32`） |
| 副行 | 还剩多久 + 已经跑了多久 |
| 进度条 | 清单完成度（`in_progress` 按半条计） |
| 左下 | `3/7 项`，没有清单时退化为「第 N 步」 |
| 右下徽章 | 置信度：样本不足 / 粗略 / 中等 / 较准 |
| 第三行 | 正在做的那一条（`正在做：…`） |

## 三个刻意的设计选择

**1. 等你的时间不算工期。** 一轮里 `ask_user_question` 与 `approval/asked`
期间整个回合是挂起的。如果把这段算进「已用时长」，一次授权等待就能把 ETA
推到几小时之后，而且再也收不回来。所以挂起时长从 elapsed 里扣掉，挂起时
挂件上会显示 `⏸ 等你操作，这段时间不计入工期`。

**2. 没样本就说没样本。** 一轮刚开始、清单一条都没勾时，任何数字都是编的。
这时大字显示 `—`，副行写「还看不出节奏」，而不是给一个两分钟后就会打脸的
时间点。置信度徽章也同步降级——**先承认不知道，比给一个错的数字有用**。

**3. 平滑而不是重算。** 每条事件都重算会让 ETA 抖动成随机数。剩余时长用
EWMA（α = 0.32）慢慢挪过去，用户看到的是一个在收敛的估计，不是一个乱跳的
读数。

## 估算来源

四个互相独立的估计，谁有样本用谁，按样本强度加权：

| 来源 | 公式 | 何时生效 |
| --- | --- | --- |
| `progress` | 净工期 × 剩余条数 / 已完成条数 | 清单里已有条目被勾掉 |
| `pace` | 平均步时 × 剩余条数 × 每条目步数 | 本轮已有 ≥2 个步长样本 |
| `unit` | 跨轮单条平均耗时 × 剩余条数 | 本轮没有可外推进度，但历史有单条样本 |
| `history` | 整轮历史均值 − 已跑 | 连清单都没有，且历史 ≥2 轮 |

子代理会话（`origin: 'subagent'` / `delegationDepth > 0`）一律不显示——
你要等的是主对话，不是某一路子代理跑完。

## 安装

```bash
# 本地开发（从目录链接，改完重启 DSH 即生效）
dsh plugin --profile desktop add link:<本目录绝对路径>
```

装完**重启 DSH**。挂件默认出现在右下角。

## 操作

- **拖动**：按住标题行拖，位置会记住（窗口变小会自动夹回屏幕内）。
- **收起**：标题行右边的 `−`。
- **隐藏**：`×`。隐藏后在右下角**双击**可以叫回来——不往页面上放常驻恢复按钮，
  因为点 `×` 的意图就是「别碍事」，再摆个按钮等于没关。
- 这些偏好存在 `localStorage`（键 `dsh-eta-forecast:v1`），不占宿主配置。

## 它不做什么

- **不注册任何写接口。** 只有两个只读路由（脚本本体与快照），没有配置、没有
  凭据、没有文件写入 ⇒ 没有攻击面，局域网里看也安全。
- **不 import 宿主服务**（`webServer` 除外，且用 `ctx.inject` 动态等待）。老宿主
  少一个服务时，插件降级而不是整个不 apply。
- **不在页面里重算。** 公式只存在于 `lib/forecast.js` 一处。前后端各写一遍是这类
  小挂件最常见的坏味道：两边一改就悄悄不一致。

## 结构

```
lib/forecast.js     纯估算核心（无 IO / 无 DOM，可 node --test）
lib/index.js        宿主半侧：订阅 session/event、注入页面、两个只读路由
assets/eta-client.js 浏览器半侧：每 2 秒拉一次快照，只负责画
test/forecast.test.js 13 个用例，全部在测「会算错的地方」
cordis.patch.yml    bundle 挂载声明
```

跑测试：

```bash
node --test "test/*.test.js"
```

## 已知边界

- ETA 依赖 todo 清单。模型这一轮**没写清单**时，只能退化到步长/历史兜底，
  置信度会明显下降——这不是 bug，是「没有可观测进度」的诚实表现。
- 多会话并行时只显示「优先级最高」的那一条（运行中的优先，其次最近有事件的）。
  完整快照在 `/dsh-eta/state.json` 里，最多 8 条。
- 桌面端的注入走 `webserver/index-inject` 的内联 script 行，并**吞掉加载失败**：
  路由不在就静默降级，宿主永远不会因为本插件起不来。
